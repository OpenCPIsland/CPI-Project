The path for igloo music: Assets/Game/Audio/MUS/Igloo/

An example of a Igloo track name that is unclocked via level up: Assets/Game/Audio/MUS/Igloo/MUS_Igloo_Level1_BewareTheDragon.ogg

An example of a Igloo trrack name that is unlocked during an event: Assets/Game/Audio/MUS/Igloo/MUS_Igloo_Holiday2017_AllAboardForTheHolidays.ogg

Make sure to match the other tracks in this folder import settings on any new tracks that you might add. The imort settings are in the Inspector tab.
