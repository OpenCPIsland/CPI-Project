Before using these steps to restore FBX models, check in Unity on the selected mesh inspector. Do you see the color float? If yes, you can skip the step where the video shows to add the color white. If it doesn't show the color float, proceed with this step.


In my How to restore FBX models video, I showed that you can't restore bones with Blender, there is a different set of instructions for that which requires AutoDesk Maya which I won't show due to Maya requiring a license and the program is designed to show your name.

If you are restoring a model that has a material, I recommend tying said material to the imported FBX to save on the amount of cached materials in the project.
